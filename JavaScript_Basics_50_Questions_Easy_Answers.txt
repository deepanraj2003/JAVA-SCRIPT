JAVASCRIPT BASICS - 50 QUESTIONS & EASY ANSWERS
=======================================================

1. What is a variable in JavaScript?
Answer: A variable is like a box that stores a value.
Small example:
let age = 25;
// age stores 25

-------------------------------------------------------

2. What are the three keywords used to create variables?
Answer: The three keywords are var, let, and const.
Small example:
let age = 25;
var name = "John";
const pi = 3.14;

-------------------------------------------------------

3. Write the syntax to create a variable using var.
Answer: Use the var keyword followed by the variable name and value.
Small example:
var age = 25;

-------------------------------------------------------

4. Write the syntax to create a variable using let.
Answer: Use the let keyword followed by the variable name and value.
Small example:
let age = 25;

-------------------------------------------------------

5. Write the syntax to create a variable using const.
Answer: Use the const keyword followed by the variable name and value.
Small example:
const age = 25;

-------------------------------------------------------

6. What is declaration?
Answer: Declaration means creating a variable without giving it a value yet.
Small example:
let age;

-------------------------------------------------------

7. What is initialization?
Answer: Initialization means giving a variable its first value.
Small example:
let age = 25;

-------------------------------------------------------

8. What is reassignment?
Answer: Reassignment means changing the value of an existing variable.
Small example:
let age = 25;
age = 26;

-------------------------------------------------------

9. What is redeclaration?
Answer: Redeclaration means declaring the same variable again with the same keyword in the same scope.
Small example:
var age = 25;
var age = 30;

-------------------------------------------------------

10. Which keyword allows redeclaration?
Answer: The var keyword allows redeclaration.
Small example:
var age = 25;
var age = 30;

-------------------------------------------------------

11. Which keyword allows reassignment?
Answer: var and let allow reassignment.
Small example:
let age = 25;
age = 30;

-------------------------------------------------------

12. Which keyword requires initialization when declared?
Answer: const must be given a value when it is declared.
Small example:
const age = 25;

-------------------------------------------------------

13. Identify the declaration and initialization: let age = 25;
Answer: Declaration: let age. Initialization: giving it the value 25.
Small example:
let age = 25;

-------------------------------------------------------

37. Can a const variable be reassigned?
Answer: No. A const variable cannot be given a new value.
Small example:
const age = 25;

-------------------------------------------------------

38. Can a const variable be redeclared?
Answer: No. A const variable cannot be redeclared in the same scope.
Small example:
const age = 25;

-------------------------------------------------------

39. What is wrong with this code? const age; age = 25;
Answer: const must be initialized when it is declared. Give it a value immediately.
Small example:
const age = 25;

-------------------------------------------------------

40. What happens here? const price = 500; price = 1000;
Answer: A const variable cannot be reassigned, so changing its value is not allowed.
Small example:
const price = 500;

-------------------------------------------------------

43. Which keyword should you use if the value should not be reassigned?

44. What is the difference between let and const?
Answer: let can be reassigned, while const cannot be reassigned. Both cannot be redeclared in the same scope.
Small example:
let age = 20;
age = 21;

const country = "India";

-------------------------------------------------------

45. What is the difference between var and const?
Answer: var can be reassigned and redeclared. const cannot be reassigned or redeclared.
Small example:
var age = 20;

const country = "India";

-------------------------------------------------------

Answer: console.error() displays an error message in the browser console.

-------------------------------------------------------

50. What is the purpose of each: alert(), prompt(), confirm(), document.writeln(), console.log()?
Answer: alert() shows a message. prompt() asks the user for input. confirm() asks for confirmation. document.writeln() writes content on the webpage. console.log() prints information in the browser console.
Small example:
alert("Welcome!");
prompt("Enter your name:");
confirm("Continue?");
document.writeln("Hello");
console.log("Hello");
